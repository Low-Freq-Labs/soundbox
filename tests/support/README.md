# Shared test support

Pure reusable builders and source readers, separate from discovered test modules.

- `audio.py`: generated bare PCM input for native registration fixtures.
- `library.py`: deterministic XML builders for library/export fixtures.
- `native_library.py`: synthetic encrypted DB fixtures; never source authority.
- `native_source.py`: canonical native/shader source loading used by independent oracles.

Keep imports free of discovery, app creation, live state, Keychain and network access.
Authority-specific setup/assertions remain with their domain suites.
Moving a builder must preserve generated bytes, fixture ownership and discovered case IDs.

Run affected suites, then the root `./check.sh` for exact inventory reconciliation.
