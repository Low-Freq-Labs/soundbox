## Validated: codebase cleanup

All authored code/current guides have recorded full-content review; changed ownership contracts received independent review.

- Ordinary desktop controls/services prepare before interaction; connected-device work stays on demand.
- First-frame selected artwork, browser place, keyboard holds, transport and native musical timing remain guarded.
- Cohesive internal services share mechanics while authorities/recovery remain domain-specific.
- Confirmed lifecycle, cache-admission, source-identity and publication bugs have disposable regressions.
- Authored-folder READMEs stay within 25 lines; the layout gate enforces coverage and boundaries.
- The dated 2,886-case gate, both signed profiles and isolated readiness pass against 729 frozen inputs; startup/RAM costs are recorded.

Personal build 169 is installed and accepted. Old app/packaging copies are retired at Sonny's request. His wrap-up publishes the validated source; current provenance and observed app state are in HANDOFF.

No new feature redesign, dependency upgrade, state schema migration, live-source test or device erase belongs to this pass.

## Next architecture work

- Per-song durable state with ordered publication, preserving persist-before-presentation and newest drafts.
- Bounded queue fairness without changing accepted waveform → BPM → key ordering or the shared source lane.
- Immutable selected export snapshots with complete source-overlap guards.
- Further controller/planner extraction where it creates a tested ownership boundary; avoid cosmetic mixin splitting.

The [performance record](performance-audit.md) describes measured costs and limits. Do not improve timing by postponing ordinary UI or removing guards.

## Independent acceptance gates

- Native source domains retain exact accepted library/schema/version authorities. Broader codecs, existing-analysis replacement, gain/metadata, intelligent/cloud edits and new write scopes need separate proof.
- Preserve conversion originals, cues/grids, native memberships and disposal receipts; never restore an old whole library to fix one component.
- Physical stock/dual/Rockbox reconnect, sync, cancellation, firmware and eject acceptance remains open. Preserve generation-58 recovery.
- Dedicated CDJ USB export maintains both catalogs; broader player/control/OneLibrary hardware acceptance remains open.
- Public distribution still needs dependency/service clearance, notices, signing/notarization, clean-machine upgrades and permissions/hardware coverage.
- Embedded-art extraction, schema2→3 migration, additional stock models, Windows and full Rockbox ReplayGain remain deferred.
