# Native-library research

Offline registration/analysis proofs and separately approved historical source pilots.

- [Proof contracts](PROOFS.md): workspace, identity, component, registration and analysis evidence.
- `registration*` / `analysis*`: explicit captured inputs and bounded proof/pilot tooling.
- [renderer](renderer/README.md): local packet rendering helper.

Production APIs have independent accepted authorities; research never provisions them.
Completed pilot approvals do not authorize replay, new imports or native-app inputs.
Preserve unresolved recovery and original evidence. Never run tools against guessed live paths.

Run synthetic proof suites through the root `./check.sh`.
