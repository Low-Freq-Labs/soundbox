# Research

Explicit offline experiments and historical source pilots; excluded from app packages.

- [cdj_export](cdj_export/README.md): legacy codecs, reference export comparison and playlist proofs.
- [native_library](native_library/README.md): registration/analysis reference and acceptance tools.

Production code must never import research. A proof or old pilot approval grants no production authority.
Use explicit frozen captures and disposable copies; never discover live sources/devices implicitly.
Private audio/database snapshots stay in the ignored reference roots, outside this source tree.

The root `./check.sh` lints research and runs its synthetic contracts.
Read each domain guide before invoking a tool; publication/replay needs its own current scope.
